# ناقد (Naqid) - وكيل التدقيق الذكي لواجهات وتجارب الويب 🔍🤖

**ناقد (Naqid)** هو وكيل ذكاء اصطناعي تفاعلي صُمم خصيصاً كنموذج أولي للهاكاثون لتدقيق صفحات الويب تماماً كما يفعل المستخدم الحقيقي وخبير الجودة (QA / UX Auditor).
يقوم الوكيل بتشغيل متصفح خفي (Chromium عبر Playwright) بأبعاد شاشات الحواسيب وشاشات الهواتف المحمولة، ويلتقط إشارات متعمقة من شجرة الـ DOM (أخطاء الكونسول، الطلبات الفاشلة، الصور التالفة، التجاوز الأفقي، اقتطاع النصوص، صغر أهداف النقر، وغياب التسميات التوضيحية)، ثم يحلل لقطات الشاشة بواسطة نموذج الذكاء الاصطناعي البصري (Google Gemini Vision)، لإنشاء تقرير مفصل يوضح مواضع الخلل، كود الإصلاح المقترح، وسيناريوهات فحص تلقائية بـ Playwright.

---

## 🌟 المميزات الرئيسية

1. **فحص ثنائي العرض (Dual Viewport Audit):** محاكاة واقعية على دقة الحاسوب (1440x900) ودقة الجوال الحديث (390x844).
2. **استخراج إشارات الـ DOM الحية:**
   - رصد أخطاء الجافاسكريبت بالكونسول (`console.error` و `pageerror`).
   - تعقب موارد الشبكة الفاشلة وعناوين الـ 404.
   - كشف التجاوز والفيضان الأفقي (`scrollWidth > clientWidth`).
   - العثور على النصوص المقتطعة بالحاويات ذات الحجم الثابت.
   - تحديد أزرار وروابط اللمس الدقيقة الأصغر من الحد الأدنى القياسي (44x44px).
   - التحقق من نصوص الـ `alt` البديلة للصور وتسميات النماذج `labels`.
3. **تحليل الرؤية المتقدم بالذكاء الاصطناعي:**
   - استخدام نموذج Vision LLM لكشف التداخلات البصرية، ضعف التباين اللوني، والتفاوت في الهوامش والمحاذاة.
   - توليد كود إصلاح دقيق (CSS / HTML / JS).
   - كتابة كود اختبار Playwright (Python) لاختبار كل مشكلة آلياً.
4. **واجهة عربية عصرية وداكنة (RTL Dark Mode):**
   - مؤشر دائري تفاعلي لدرجة الجودة من 100.
   - تتبع متحرك لخطوات الوكيل خطوة بخطوة أثناء الفحص.
   - فلاتر سريعة حسب مستوى الخطورة (حرجة، عالية، متوسطة، منخفضة) والتصنيف.
   - استعراض فوري لصور الشاشات مع أزرار نسخ للأكواد بنقرة واحدة.
   - تصدير التقرير الكامل بصيغة JSON.
5. **وضع العرض المضمون (Demo Mode Fail-safe):** إذا لم يتوفر مفتاح API لـ Gemini أو تم تفعيل خيار العرض، يعتمد النظام تلقائياً على التقرير التجريبي المحفوظ دون أن يتعطل العرض التقديمي.

## 🐛 العيوب المزروعة في الصفحة التجريبية (Planted Bugs)

تحتوي صفحة `demo/broken_page.html` (متجر الأفق) على 10 عيوب واقعية مزروعة ومدروسة بدون أي تعليقات في الكود:

1. **تداخل شارة الخصم مع العنوان الرئيسي (Overlapping Hero Banner):** شارة إعلانية مطلقة الموضع (`position: absolute; top: 15px; right: 40px;`) تحجب نص العنوان الرئيسي `<h1>`.
2. **صورة منتج تالفة (Broken Image 404):** بطاقة سماعات الرأس تشير إلى مسار غير موجود يسبب خطأ شبكة 404 و `naturalWidth == 0`.
3. **نص رمادي فاتح فوق خلفية بيضاء (Low Contrast Text):** نص تنبيه الشحن بلون `#e5e7eb` على خلفية `#ffffff` (تباين غير مقروء ومخالف لمعايير WCAG).
4. **زر اتخاذ إجراء بنص مقتطع (Clipped CTA Button):** زر بعرض 110 بكسل مع `overflow: hidden` و `white-space: nowrap` يقطع نص العبارة الدعائية.
5. **أهداف نقر صغيرة جداً على الجوال (Tiny Tap Targets):** أزرار التحكم والبحث في شريط الترويسة بمقاس 20x20 بكسل فقط (< 44x44px).
6. **شبكة منتجات تفيض أفقياً على الجوال (Horizontal Overflow Grid):** استخدام عرض ثابت 960 بكسل في شبكة المنتجات مما يسبب شريط تمرير أفقي على شاشة الجوال (390 بكسل).
7. **نموذج إدخال بدون تسميات توضيحية (Missing Labels & Placeholders):** حقول الاشتراك بالنشرة البريدية تفتقر إلى وسم `<label>` أو سمة `placeholder` أو `aria-label`.
8. **غياب النصوص البديلة عن الصور (Missing Alt Attributes):** صور المنتجات في البطاقات تفتقر تماماً لسمة `alt`.
9. **تفاوت عشوائي في المحاذاة والهوامش (Misaligned Elements & Spacing):** بطاقات المنتجات تستخدم هوامش علوية عشوائية متفاوتة (`margin-top: -12px` و `38px` و `18px`) مع أزرار محاذاة غير متطابقة.
10. **خطأ برمجي في الكونسول وزر غير فعال (Console Error & Inactive Button):** استدعاء دالة غير معرّفة `initAnalyticsAndPerformanceTracking()` عند بدء التحميل وزر `quick-checkout-btn` معطّل بـ `onclick="void(0)"`.

## 🚀 خطوات التثبيت والتشغيل (Setup Guide)

### على نظام Windows:

1. **إنشاء البيئة الافتراضية وتفعيلها:**
   ```powershell
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   ```

2. **تثبيت حزم بايثون:**
   ```powershell
   pip install -r requirements.txt
   ```

3. **تثبيت متصفح Playwright Chromium:**
   ```powershell
   playwright install chromium
   ```

4. **تجهيز ملف البيئة:**
   ```powershell
   Copy-Item .env.example .env
   ```
   *(اختياري: افتح ملف `.env` وأضف مفتاح `GEMINI_API_KEY` الخاص بك لتفعيل الفحص المباشر بنموذج الذكاء الاصطناعي، أو اتركه فارغاً للاعتماد التلقائي على وضع الديمو الاحترافي السريع).*

5. **تشغيل الخادم:**
   ```powershell
   uvicorn backend.main:app --reload --port 8000
   ```

6. **افتح المتصفح على الرابط:**
   ```text
   http://localhost:8000
   ```

---
